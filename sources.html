Method

How the verification was performed

  1. One primary page per claim. Each row records the URL of the page the value was read from, and the page was opened in this session. No value was carried over from a prior build without being re-read.
  2. Two readings, one record. The brief distinguishes what a source states from what this brief concludes: "verified" means quoted from the page; "derived" means arithmetic on verified values, with the formula written in the row.
  3. Blank over plausible. If a page did not answer the question - a county unemployment rate, a parcel's fire zone, an official population projection that ships as an unreadable workbook - the value is blank and listed on Flagged for review.
  4. No blending. City, county and metropolitan figures are never averaged or combined into a synthetic "central Los Angeles" number. Geography is printed in every row.
  5. Automated gate. scripts/validate_site.py fails the build if a row in an unverified or withheld state contains a number, if any table row lacks an official source link, if a link points outside the official allowlist, if an internal link or anchor does not resolve, or if an email or phone pattern appears.

Reproduce

Rebuild this site from the dataset

Build: python3 scripts/build_site.py

Validate: python3 scripts/validate_site.py

Preview: python3 -m http.server 4173 --bind 0.0.0.0

The dataset lives in scripts/site_data.py; the model constants and all page templates live in scripts/build_site.py. A JSON export of the published rows is written to data/published-records.json on every build for audit.

Limits

What this brief is not

  • Not an appraisal. No property-specific value is stated. The model runs ranges of labelled assumptions.
  • Not tax, legal or investment advice. Statutory rates are quoted from the agency that administers them; how they apply to a specific transaction requires a professional opinion.
  • Not parcel-specific. No parcel has been identified, by design. Where a conclusion depends on the parcel, the row says "parcel not mapped" rather than guessing.
  • Point-in-time. Values are as published on or before {ACCESSION_DATE}. Labour, price and filing data are revised; re-read the linked page before relying on a figure.
  • Not complete on tenant credit. No credit rating, no audited financial statements beyond the earnings release, and no location-level performance were reviewed.

Privacy: aggregated public statistics only. No personal identifiers are stored in this repository or served by this site.
