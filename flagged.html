Repository irregularities

Two findings that are about the repository, not about the property

R-05 - conflict markers on the shared board. COORDINATION.md on main contained unresolved git conflict markers (<<<<<<< HEAD, =======, >>>>>>> origin/main) from overlapping sessions, which made the task board unreadable. It is rebuilt as a single board on this branch; every prior session's record is preserved in its session log, and no prior work was deleted.

R-06 - two publishers for one site. The repository's GitHub Pages source is the legacy branch build from main (root), while the workflow also ran an artifact deployment, so two processes could publish the same URL. The workflow now validates only, which makes the published site exactly the repository root. The live URL is checked after merge and the result is recorded on the task board.

Prior sessions

Preserved work from parallel sessions

Earlier sessions published their own sites and verification ledgers on this URL. Nothing was deleted. The build that was live on main before this integration - including its Verification audit page, which re-checked 33 figures and corrected two - is preserved at archive/legacy-2026-11-07/main-d2a64a9e/audit.html and remains readable. Three of its findings that could be re-verified here were absorbed into this dataset: metropolitan GDP (ECO-24), county GDP (ECO-25) and the USGS 30-year regional earthquake probability (CAT-19). Its FEMA National Risk Index values were withheld there for want of a readable official page, and they are not published here either.

Privacy

Privacy audit of this publication

What is published: aggregated government statistics, public-company filings, statutory rates, and the official page each came from.

What is not published: owner name, street address, parcel number, ownership entity, lease document, rent figure, debt balance, assessed value, insurance details, or any individual financial circumstance. These appear in the tables only as [Withheld].

What the site collects: nothing. No cookies, no analytics, no third-party scripts, no forms, no fonts or assets loaded from other domains. The only external requests are the source links a reader chooses to click.

What the repository contains: the same public data plus the build script. A validation step scans every page for email-address and phone-number patterns and fails the build if one appears.

Privacy: aggregated public statistics only. No personal identifiers are stored in this repository or served by this site.

Every table value links to the official page it was read from on 2026-11-07. Blank cells are unverified or withheld by policy — they are listed on Flagged for review. This is analysis for the owner, not appraisal, legal, tax or investment advice.
