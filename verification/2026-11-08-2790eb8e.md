## Verification limitations and open irregularities

- `python3 scripts/validate_site.py` checks the eight pages, table-row citations, local navigation/fragments, allowed external hosts, and simple visible email/phone patterns. It does **not** test that every official link is reachable, substantiate claims, or prove absence of all personal information.
- `node scripts/verify-data.mjs` is a stale gate for the retired data-driven site; it fails on canonical navigation and totals and is not the CI gate. `python3 tools/check.py` passes for a different archived dossier, not this dashboard.
- `gh api repos/wingbangboozle1-lang/Jack1/pages` reports legacy `main` root source. Attempt to switch to Actions returned HTTP 403. The root source exposes historical pages and repository files, including unverified old analyses. The Actions artifact's restricted contents do not make those files private. Published on Flagged for Review and corrected README and audit wording. Do not put sensitive information in a public repository.
- Several old overlapping PRs remain open; no unreviewed wholesale replacement was merged. The board's historical PR #9 entry is inconsistent as described in the earlier audit.
- Exact location, rent, actual counterparty, lease and renewal rights, valuation, debts, tax situation, and portfolio objectives are not independently available. There is no defensible personalized sell-or-renew verdict or numerical property projection; the added scenario framework has intentionally blank outputs.
- Links in the static validator are not a network-availability check. Other rows and external URLs require further independent verification; no claim of a complete line-by-line audit is made.

- The claimed removal of the broken LA County heat-brief link was incomplete: it remained in the audit page. On 08 Nov the official county URL returned a not-found page. Substituted a checked NOAA regional heat-event source with clearly changed scope.
