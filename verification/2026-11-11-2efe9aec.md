The published brief had a coverage checklist but no register of the questions that gate the
sell-versus-renew decision, which is the explicit owner request ("a clear list of questions,
information and answers that need to be addressed before any decision can be reasonably made …
suggestions to discover missing information"). Added as the `questions` key in the dataset and
rendered as the first table on `requirements.html`:

- 23 questions, each with a verified answer, an explicit blank, or a stated rule-with-blank-amount;
- status labels: answered (3), derived (2), partial (10), open (4), blocked (1), analysis (2);
- every row states how to obtain what is missing and links the official source;
- a nine-step discovery plan orders the document requests (title/survey, lease and amendments,
  cash-flow evidence, credit file, condition and environmental, insurance, valuation, tax and
  financing, parcel-keyed market evidence).

Blank answers render as genuinely empty cells — no placeholder value, no estimate. An automated test
(`test_decision_question_register`) fails the build if a question loses its source, uses an unknown
status, or fills a cell whose status is "open".
