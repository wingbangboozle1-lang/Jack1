## 3. Irregularities (all publication-safe; listed on Flagged for Review)

1. **Treasury row is now stale as a "current" reading.** The 10 Nov row is correct as dated. The official curve shows the 10-year at 5.15% on 13 Nov (up 17 bp since 10 Nov). Any decision that uses a rate should use a dated reading and refresh it before acting. Indicative sovereign benchmarks only, not cap rates.
2. **CAL FIRE PDF is served from an Azure CDN hostname** (`34c031f8-…-cdn-endpoint.azureedge.net`), not a `.gov` host. The content is the State Fire Marshal / CAL FIRE acreage table and matches the published figures. A reviewer should confirm it from the State Fire Marshal pages before citing it in a formal document.
3. **Legacy files outside the published set cite non-government sites, some labelled "VERIFIED."** A census of tracked files (excluding `archive/` and `verification/`) found more than 40 non-government or non-.gov hosts. The largest by link count were `losangelesrc.org` (45), `plainhazard.com` (44), `usschoolindex.org` (39), `explore.disasteraware.com` (31) and `teamcirca.com` (25), along with `cove.inc`, `netleaseadvisor.com`, `nnnworld.com` and news sites. Example: `data/property_data.md` (a 6 Nov 2026 legacy file) labels rows "VERIFIED" from `teamcirca.com` and `losangelesrc.org`. **None of these hosts appear on the 13 published pages**, which the validator restricts to an allowlist. They are not cited as verified anywhere in the published dataset. They remain in Git history and the working tree. Removal would need an owner-approved cleanup PR; this session did not delete them.
4. **Hosting intermediaries.** Published links include `services.arcgis.com` (FEMA NRI query), `lapdonlinestrgeacc.blob.core.usgovcloudapi.net` (LAPD PDFs) and the CAL FIRE CDN. Each serves an official publisher's content. They are flagged rather than replaced because no `.gov` alternative with the same data was found on the same day.
5. **Privacy scan.** A regex scan of the tracked tree for email, phone, APN-like and street-address patterns returned no personal identifiers. The only matches were test fixtures in `tests/`. No property, owner, lease-party or personal financial identifier was added in this session.
