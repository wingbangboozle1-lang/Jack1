# Jack1 — SP-01 NNN Property Decision Dossier

Anonymized, source-verified analysis of a single-tenant **Jack in the Box** property on a
**NNN lease** in **Central Los Angeles** with a lease expiration in the **2030–2035** window.

**Question:** sell before expiry, or renew and hold?

**Live site:** https://wingbangboozle1-lang.github.io/Jack1/

## Privacy

The subject property is referred to only as `SP-01`. No address, owner name, parcel
number, rent, or NOI appears anywhere in this repository or on the published site.
Anything only knowable from private documents is published as `[WITHHELD]` or as a
labelled assumption band. See `COORDINATION.md` §1.
