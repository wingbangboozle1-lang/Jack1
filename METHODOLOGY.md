# Current methodology (2026-11-13)

The current public product is generated by `scripts/build_public.py` from `data/verified-2026-11-10.json` (file name is the original dataset vintage; `meta.date` is the public revision date). `scripts/projection_model.py` keeps [California DOF](https://dof.ca.gov/media/docs/forecasting/Demographics/projections/P2A_County_Total.xlsx) and [SCAG](https://scag.ca.gov/sites/default/files/2024-05/appendix_i_updated_tables_508_final.pdf) forecasts separate; it does **not** extrapolate a parcel revenue or invent missing inputs. The browser worksheet starts blank, stores no entries and makes no data requests. Official observations specify geography, period and linked source. Calculations are labeled derived. Unverified property values are blank and flagged. Scenario discussion is judgment, not a quantified forecast.

Reproduce from the repository root:

```sh
python3 scripts/build_public.py --check
python3 -m unittest discover -s tests -p 'test_*.py'
python3 scripts/validate_site.py
python3 scripts/build_public.py --out _site
python3 scripts/validate_site.py --site _site --artifact
```

The tests check generation consistency, source-link presence/host allowlist, local links, blank-value defaults and common privacy patterns; they do **not** prove that every linked official page still prints every asserted value. Substantive cross-checks include the [full 2026-11-10 ledger](verification/2026-11-10-8d46ab6c.md), the [targeted 2026-11-11 ledger](verification/2026-11-11-db9ded39.md), the [2026-11-12 re-read log](verification/2026-11-12-83da931a.md), and the [2026-11-13 C-1 follow-up](verification/2026-11-13-c1cabdaf.md). The November 13 pass updates current Treasury-rate consumers to the separately dated November 13 close, reconciles the FEMA county layer's NRI v1.20 identity, and corrects a source link for additional county hazard ratings; it is not a fresh line-by-line re-open of all published observations. Source access dates remain source-specific. Rolling official sources must be re-read before reuse. This method cannot decide the individual property's best investment action without private evidence. Never publish identifying details.
