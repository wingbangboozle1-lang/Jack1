Repository findings

Irregularities found in the repo

  1. Landing-page contradiction (fixed). The previous landing page stated a $1.355 trillion 2024 metro GDP figure and a “#2 county economy” ranking in body copy while its own metric card showed the discontinued 2023 metro series. Neither claim could be traced to an official page. Both were removed; the item is recorded as F-11 and F-12.
  2. Stale labour market (fixed). The previous build showed December 2025 as the latest county month although BLS had published September 2026. Updated, and recorded as F-14.
  3. Published annual average replaced by a computed one (fixed). The previous build showed 5.6% as the 2025 county annual rate. BLS publishes 5.7%. Corrected to the published value; recorded as F-13.
  4. CAL FIRE percentage claims (withheld). A “26% Southern California / 35% statewide expansion of Very High zones” appears in earlier drafts. The official State Fire Marshal acreage table publishes acreage, not those percentages. Verified acreage is published instead; recorded as F-10.
  5. Unsourced hazard caveat (removed). A limitation cell previously asserted that LA County “added 440,000+ acres … including 30% increase in highest severity” without a citation. Replaced with the official acreage table.
  6. FEMA NRI values (withheld). County risk scores and expected annual loss appear in earlier drafts but were not readable from an official FEMA page in two independent audits. FEMA delivers NRI v1.20 through its RAPT mapping tool, not as a published county table. Recorded as F-08.
  7. Many parallel builds in the repository. The repo contains several complete, overlapping site builds under pages/, site/, archive/, and older root pages, plus multiple open pull requests proposing full replacements of the root pages. Only the fifteenpages built by this session are deployed by the current workflow.
  8. GitHub Pages build source. An earlier session recorded that switching Pages from the legacy source to GitHub Actions returned HTTP 403. The deploy workflow in this branch is the Actions path; if the repository setting still points at the legacy source, the site is served from the branch root and both paths produce the same files.
