Reproducibility

Build and gates

  • python3 scripts/build_public.py --check verifies canonical pages match the dataset.
  • python3 -m unittest discover -s tests -p 'test_*.py' tests projection arithmetic, gating, build determinism, and privacy/source rules.
  • python3 scripts/validate_site.py validates pages, row source links, allowlist, local links, blanks, and privacy patterns.
  • Public artifact contains only curated pages, assets, and generated projection data. Historical builds remain in Git but are not published.
