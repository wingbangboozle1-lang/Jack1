Tenant deep-dive — Jack in the Box Inc. (NASDAQ: JACK)

The single most important variable in this decision. Built from SEC filings (FY2025 Form 10-K; FY2026 Form 8-Ks and earnings releases) with clearly-labeled industry reporting. Balance sheet is stressed; the company is closing restaurants and selling real estate. No personal information is published.

Headline. JACK is a leveraged turnaround: total debt ≈ $1.5B, net debt / Adjusted EBITDA 6.3x (Q3 FY2026, improved from 6.9x in Q2 FY2026), same-store sales negative, two leadership transitions in six months, a 150–200 restaurant “JACK on Track” closure program plus ~50–100 more FY26 closures, and an active corporate real-estate-sale program (≈$26.7M generated YTD through Q3 FY26; $35–45M expected FY26). The landlord’s true counterparty is usually a franchisee LLC — guarantee type unverified.

5 · What this means for a NNN landlord

Against holding passively to 2030–35

  • 6.3x net leverage; FY26 Adj. EBITDA guide cut twice ($235M→$230M).
  • Negative same-store sales for multiple years; transactions falling.
  • Closure program can logically select this asset (150–200 + ~50–100 FY26).
  • Parent is itself monetizing owned real estate — not a natural renewing buyer-landlord partner.
  • 93% franchised — renewal decision sits with a franchisee’s P&L (AUV $1.874M, franchise margin 37.4% and falling).

For a disciplined renewal — only if ALL true

  • Unit is profitable: AUV ≥ system average; occupancy cost ≤ ~15% of sales.
  • ≥10-year extension signed with ≥2% escalations (preferably CPI-linked).
  • Corporate or creditworthy franchisee guarantee verified; estoppel delivered.
  • Store confirmed OUT of the closure program — in writing from the franchisor.
  • Insurance current (incl. earthquake); NNN pass-throughs compliant.
Bottom line. See the Decision page: negotiate renewal NOW with a hard fuse (≈2028) — if a guaranteed ≥10-year reset is signed, hold; otherwise sell 2026–2028 while remaining term still supports NNN pricing, ideally via 1031. This Tenant page is the evidence base for the trigger conditions.
