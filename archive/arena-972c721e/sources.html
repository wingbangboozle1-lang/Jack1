How to check any number on this site

  1. Find the fact ID on any table — for example F001.
  2. Follow the source chip next to it (for example S02).
  3. Open the publisher's page and compare the figures. The note under each source records exactly what was seen, including any qualifying language on the page.
  4. If a number cannot be reproduced from that page, treat it as an error in this file and flag it.

Deliberate exclusions

  • No broker listings or market reports are used as evidence. A listing is an asking price by an interested party, not a verified transaction, and no official series publishes net-lease cap rates or sub-market retail rents.
  • No data aggregators are cited for anything a primary source covers. Where aggregators disagreed with each other by more than 20% (school enrolment), the primary federal source was used instead.
  • No projections from private forecasters are presented as data. The projection on this site is a transparent deterministic model, not a purchased forecast.

Privacy: this site contains no address, parcel number, owner name, rent, or NOI. The subject property is referred to only as SP-01. Anything knowable only from private documents is shown as [WITHHELD] or as a labelled assumption.
